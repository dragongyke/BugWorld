# BugWorld 1.0.9 · 环绕星夜花园

分支 `codex/bugworld-v1`，PICO Spatial SDK 6.1.0。延续已验收的 1.0.8 画板、多窗口画具及昆虫模型。

## 本次变化

- 场景围绕入场位置与朝向布置；保留植物尺寸，缩减到 10 片荷叶、4 朵花、6 组水草、2 个木质主体。分离叶片与木头，树干底部接入水面，重建全部路线。
- 明亮蓝紫星空纹理、匹配环境光与水面反射；天空取消面剔除，水面减弱法线、提高粗糙度，去除方向性条纹。天空黑底的修正效果尚待真机确认。
- 移除 Stage 常驻白色工具栏。前左方固定魔法球返回画板，凝视时显示标签；加载/错误时仍可退出。音量调整移到 Shared Space 的“声音”，首次入场有短暂指引。
- 每只昆虫独立交互范围与原生 Hover。看向目标并捏合选择，再稳住食指/掌心邀请；没有选择时不会自动吸引另一只。
- 落稳后停留约 3 秒；追踪失效、快速移手或手势结束取消邀请，随后连续返回原路线。触碰反应延长到 1.8 秒。

## 当前交互边界

| 对象 | 本版操作 |
| --- | --- |
| 蝴蝶 | 凝视后捏合选中，再伸出食指/摊掌并停稳约 0.7 秒邀请；可近手触碰 |
| 瓢虫 | 同样先选中，手需在它 35 cm 内；可近手触碰 |
| 独角仙、毛毛虫 | 直接 poke、捏合目标或近手触碰播放回应；不邀请到手上 |
| 所有昆虫 | 沿路线进行原有停留、爬行或飞行；每只使用一个稳定交互范围 |

交互范围不是随每根骨骼变化的精确足部/翅膀碰撞体。高亮使用 SDK 原生反馈，未把概念图的指定轮廓颜色和宽度当作已验证结果。水面使用静态反射探针，不含动态昆虫倒影。
