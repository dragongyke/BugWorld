# BugWorld 1.0.13

2026-11-04。原生 Android，PICO Spatial SDK 6.1.0。1.0.13 包含四种原有昆虫。用户随后确认了以下两张概念图，蜻蜓、蜜蜂、工蚁和蚱蜢已在 [1.0.14](Delivery-114.md) 接入。图中的配色用于展示蜡笔在翅膀、背部和腿上的效果，实际颜色由玩家绘制。

## 原生体验

| 入口 | 行为 |
| --- | --- |
| 启动和画具 | 跟随系统中英文。中文启动器名称为「我的昆虫世界」，英文为 BugWorld。品牌 Logo 恒为 BugWorld。20 色以五列四行显示，色块点击区 54 dp，右侧面板宽 360 dp、内倾 25°。 |
| TopBar | 两端固定品牌和作品册，中央纯图标逐项点击和凝视。可用物种超过四种时，中央可左右滚动，首屏显示四项半。当前四种全部可见。 |
| 画板与作品册 | 原生 Stage 上屏时最小化工作窗口。返回时主画板优先恢复，作品册仅在之前打开时恢复。昆虫放生独立等待森林就绪。 |
| 空间预览 | 捏住昆虫转动手腕，模型绕自身中心跟随手的三轴旋转。松手保留角度，下次从该角度继续。 |
| 花园路线 | 蝴蝶、独角仙、瓢虫各三条，毛毛虫两条。同种优先分配不同路线，复用时等空闲出发位置到达出生点。四种待制作昆虫各有两条路线方案。[路线与出生点](Routes.md) |
| 掌上访问 | 捏合蝴蝶、独角仙或瓢虫，再平稳摊掌。昆虫着陆后面向佩戴者，跟随同一只手约三秒，再回到预留的路线位置。掌面倾角和脚底相对位置参与定位。 |
