# 花园居民的出生点和循环路线

2026-11-04 · 原生 Stage。坐标单位为米，Y 向上，花园入口正前方为 −Z。每只昆虫从所属路线的出生点出现，每轮自然行为结束后回到同一个点。

## 八种居民的出生点

下列是从批准森林网格采样的足底原点，坐标包含沿表面法线的 3 mm 偏移。斜面和树桩上的身体朝向使用各自的表面法线。顺序对应同种居民优先占用的不同路线。

| 物种 | 路线名称与出生坐标（X, Y, Z） | 一圈的行为 |
|---|---|---|
| 蝴蝶 | 前右叶心 (1.55, 0.52, −2.65)；前低叶心 (1.38, 0.13, −1.15)；后叶心 (0.30, 0.28, 2.81) | 停 1.2 s，小步走 1.8 s，原地展开翅膀 0.75 s，飞行 24 s。每条路线沿不同方向绕行、收翅，落回原点。 |
| 瓢虫 | 前右叶缘 (1.13, 0.54, −2.65)；右叶外圈 (2.70, 0.34, −0.09)；后左叶缘 (−2.60, 0.46, 2.72) | 停 1.5 s，沿实测叶面爬 20 s，原地开甲 1.05 s，短飞 4.8 s，落回原点。 |
| 独角仙 | 倒木前段 (−1.53, 0.21, −3.47)；倒木中段 (−2.06, 0.53, −1.37)；树桩正面 (−3.33, 0.50, −3.30) | 停 0.9 s，沿树皮爬 17 s，原地开甲 1.3 s，短飞 5.8 s，落回原点。树桩上的起飞沿树皮外法线让开树干。 |
| 毛毛虫 | 前低叶外圈 (0.80, 0.21, −1.40)；后叶外圈 (0.30, 0.19, 2.27) | 沿同一叶面的封闭轨迹连续爬行，每圈 34 s。放生特效、触碰仍可使它暂时停住。 |
| 蜻蜓 | 前右叶巡塘 (1.01, 0.62, −3.02)；后叶上空折返 (−0.26, 0.33, 1.94) | 停栖后短爬，从叶缘起飞。空中巡回 22 s，中途在水面上方悬停约 1 s，再从另一方向回原叶。 |
| 蜜蜂 | 前莲花瓣 (−0.39, 0.48, −2.21)；右叶访花 (2.73, 0.31, 0.54) | 停栖、短爬、振翅，飞行 17.5 s。在前莲花或右前方另一朵莲花上方悬停约 0.7 s，再落回出生点。 |
| 无翅工蚁 | 岸地 (3.41, −0.03, 3.10)；树桩侧面 (−3.02, 1.29, −3.79) | 沿岸地或同一块树皮连续爬行，闭合回原点。 |
| 蚱蜢 | 前岸 (−0.40, −0.05, −4.20)；左侧岸地 (−5.20, −0.01, −1.00) | 前岸 → 树桩 → 低荷叶 → 前岸，19.58 s。左侧岸地 → 倒木 → 后左荷叶 → 左侧岸地，17.90 s。两条路线均在树皮和叶面走几步后停留，然后沿独立通道跳到下一处。 |

同种居民优先使用空路线。同路居民出发时间相隔固定，各自的相位经过出生点时才出现。蝴蝶、瓢虫、独角仙每路有 4 个相位，其他五种每路有 5 个。放生、触碰或访问手掌期间，同路时钟一起暂停，返回预留位置后恢复。其他路线独立行进。

## 从候选栖点到实测栖点

前低观察叶已有毛毛虫外圈和蝴蝶停栖区。蜻蜓从前右叶临水一侧出发。蜜蜂在莲花花瓣和右叶出发与返回。工蚁使用露出水面的岸地和树皮。蚱蜢的两条路线各有三个独立落脚段，跳跃通道依据场景网格复核。

新增四种昆虫的花园水平跨度分别为蜻蜓 31.2 cm、蜜蜂 18.24 cm、工蚁 14.4 cm、蚱蜢 21.12 cm。这些尺寸同时用于运行缩放和路线间距测试。每个物种至少有两条路线，八种均可容纳十只同种居民。

## 验证范围

- Blender 重新导入原森林 GLB，复测 19 条路线的支撑段。两条蚱蜢路线三个支撑段的线段插值最大离面均小于 0.37 mm。
- Kotlin 专项包含 11 个测试，覆盖全部物种连续放生、同路暂停和返回、冷热启动及周期间距。每条路线按 2,000 个相位检查同组中心距，超过该物种水平跨度加 2 cm；19 条路线两两按各 240 个独立相位检查异组间距。
- 使用 Kotlin 实际运行时坐标检查飞行中心线。蚱蜢按 0.02 s 采样，其余飞行路线按 0.1 s。共 9,869 段中心线通过 37 个森林网格的穿越检查。
- 上述测量针对足底原点、轨迹中心及给定观察位置。头显中的整只虫体、翅缘和足部接触、动态图像遮挡、放生特效及十只居民的帧率仍待确认。
