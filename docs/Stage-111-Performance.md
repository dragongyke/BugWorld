# Stage 1.0.11 · 90 Hz 优化

目标 90 Hz（11.11 ms），最低 72 Hz（13.89 ms），保持已确认的画质、完整昆虫动画、画板与入场逻辑。帧间隔、应用/空间 GPU 阶段和用户转头体验均需检查；不以平均 GPU 时间单独宣布达标。

## 当前证据

1.0.10 的 20 秒有效 trace 中，GPU 平均 17.442 ms；新增查询显示阴影平均 203 万三角形 / 332 次绘制，而可见 3D 网格约 47 万三角形 / 59 次绘制。引擎计数不是逐 pass 的 GPU 时间，尚不能推导阴影时间占比。应用回调中位约 22.22 ms，未达到最低要求。

SDK 6.1.0 字节码确认 `ShadowProjectionType.Auto/Fixed` 以及方向光阴影开关存在。PointLight 没有公开阴影开关；未假定点光源产生六面阴影。GroundShadow 是独立地面阴影机制，不能拿它关闭方向光的阴影。

## 单变量诊断

- 已确认的 1.0.10 作为基线；调试包仅切换方向光阴影投影：自动 / 覆盖花园的固定范围 / 临时无阴影。
- 固定范围保持光色、亮度、方向、场景、昆虫网格、材质与动画不变；光源的位置只用于固定阴影投影，不改变方向光照射方向。
- 临时探针读取应用私有文件，不新增 UI 或外部广播接口；正式交付前移除。无阴影仅用于归因，不作为默认画质方案。
- 每次切换有明确日志，佩戴下采集同数量、相近视角的数据，保留失败结果。随后按证据收敛正式实现。

## 2026-10-20 两轮佩戴采集

同一花园 5 只昆虫、完整骨骼动画，每段 15 秒。未锁定头显视角，不能当作严格固定画面的基准。下表 GPU 来自 `frame.spatialOverview`；FPS 来自 `com.pico.spatial.runtime` 的 `frameRate`，不是请求值 `RenderRate`。

| 配置 | GPU 均值 / P95 ms | 实际 FPS | 阴影绘制 / 三角形 | 结论 |
| --- | --- | --- | --- | --- |
| 默认 Auto，A | 17.588 / 19.525 | 45 | 334 / 2,045,268 | 未达标 |
| Fixed，12×12 m | 17.858 / 19.618 | 45 | 约 332 / 2,036,000 | 改投影未改善，撤回 |
| 恢复 Auto，B | 16.996 / 18.497 | 约 45 | 见原始计数 | 未达标 |
| 仅关闭主方向光阴影 | 9.331 / 9.918 | 90 | 223 / 1,363,548 | 定位线索；不作为交付画质方案 |
| Auto 最大距离 2 m | 17.098 / 18.979 | 45 | 334 / 2,045,268 | 缩短距离未改善，撤回 |
| 移除 opacity=1 的层级控制组件 | 7.384 / 9.368 | 90 | 334 / 2,045,268 | 阴影保留；有希望，但尚需冷启动复验 |
| 重新挂回组件，恢复 Auto，C | 9.326 / 10.035 | 90 | 334 / 2,045,268 | 未回到原先慢速，存在视角或原生状态残留干扰 |

原始 trace 和分析存于 `.work/stage111-{auto-a,fixed,auto-b,off,near,no-opacity,auto-c}*`。公开查询见 `scripts/perf/stage_budget_counters.sql`。GPU slice 未提供细分 pass 时间，三角形数量不等于 GPU 时间占比。

**不提前定因**：关闭方向光阴影的结果说明该渲染路径与高开销有关，不能据此断言阴影是唯一原因。第二轮去除不透明对象的层级透明度后，保留同样阴影计数也达到 90 FPS；但挂回后没有复现变慢，因此仍需冷启动、相近视角和视觉检查。

## 候选修正

- `InsectModel` 同时用于花园模型和昆虫。此前默认在每个根节点常驻 `OpacityControllerComponent(1)`；现在默认无控制组件，只在 opacity<1 时新建，恢复到 1 时移除。
- 保留入场/离场渐变；下一次渐变创建新组件，不复用已移除的原生组件。
- 临时阴影/透明度切换探针已从候选移除，方向光恢复批准的 Auto、强度和方向；画板生命周期不变，GLB/贴图/动画不变。
- 单元测试、Lint、APK 构建已运行成功。性能与淡入淡出仍待候选真机验证。

状态：短采样曾达 90 FPS，不能据此宣布持续运行或 10 只昆虫达标。

## 几何与灯光生命周期候选

- 几何候选保留原始顶点、UV、权重、骨骼和动画，仅简化索引；接触表面和薄翅受保护。花园 251,260 → 175,176 三角形，四种昆虫合计 340,488 → 200,646。属于有损几何简化，不能称为无损。实际 GLB 静止/运动对照、前/后/侧场景对照与数据检查均保存在 `assets-src/stage111-geometry/`。
- 40 秒佩戴采集 `stage111-geometry-worn`：GPU 均值 15.804 / P95 19.125 ms；runtime FPS 均值 50.8、范围 45–90；阴影峰值 334 次 / 1,515,744 三角形。几何下降并未达到帧率目标。
- 后续将 Shared Space 预览灯光改为仅在预览可见时创建，隐藏时释放；没有改变画板挂载生命周期，Stage 阴影仍保留。
- 40 秒 `stage111-light-lifecycle`：GPU 均值 12.214 / P95 18.467 ms；阴影峰值仍为 334 次 / 1,515,744 三角形，因此“隐藏预览灯光产生额外阴影 pass”的假设未得到支持。样本包含零绘制和低帧率段（runtime 均值 39、最小 2、最大 90），不作为稳定佩戴帧率结论，也不将两次均值差直接归因于代码改动。
- 用户随后确认：**已经完全不卡顿，HUD 约 46 FPS，不影响体验，暂时忽略帧率，优先场景设计**。这是主观流畅度验收，不是 72/90 FPS 达标。保留当前候选与原始证据，停止连续安装性能诊断包。

后续场景以此包作为体验基线。新的森林、动态水面和路线在独立资产目录制作，未验证前不覆盖当前运行版本。性能目标保留作观察指标；当前优先级按用户指示转为还原度和流畅体验。
