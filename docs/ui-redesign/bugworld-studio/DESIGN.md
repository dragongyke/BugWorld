# BugWorld · 纸间花园

## 目标与状态

2026-10-28。按用户认可的路线，先完成主画板与画具的交互原型，再经视觉确认进入 PICO 原生实现。本包是可丢弃的浏览器设计原型；不是 APK、头显截图或帧率验收。采用 OpenDesign 的设计包结构、状态覆盖和动效纪律，由本任务 Agent 直接制作；未安装或运行 OpenDesign 工作台，也未调用其云端生成服务。

## 已确认约束

- 暖白、浅紫、清晰留白；面向各年龄层，轻松创作和治愈陪伴。
- 1050 × 840 dp 主画板；右侧原生 Subwindow 宽 360 dp，左侧轴向内 25°，随主画板移动。
- 原生 TabBar 独立项目；每个昆虫一个点击/凝视目标。作品册保留左侧独立窗口。
- 四种已批准的画纸、图标和模型保持不变。打开应用从新画纸开始；作品册才是继续编辑入口。
- 本轮不改 Stage、数据格式、模型、绘画算法或窗口生命周期。

## 实施方式

选用此前提出并获准的“设计规范 → 可交互原型 → 原生小范围验收”。局部配色微调不足以暴露操作状态；直接整体重写原生 UI 会放大还原和窗口回归风险，因此本轮只交付原型。以下具体视觉值是本轮设计提案，尚待用户确认。

## 视觉语言

纸张暖白，容器奶白，墨色深紫灰。浅紫仅作为选中底色，深紫用于关键操作和凝视边框。绘画颜色继续使用应用现有十二色，颜色均有中文名称。正文采用系统中文无衬线字体，品牌沿用已批准 Logo SVG。实际纸纹由原生绘画系统提供，浏览器笔触只是交互示意。

## 空间与排版

导航条宽 780 / 1050（约 74%），根据本轮用户反馈，四种昆虫仅显示图标；无障碍名称保留，视觉上不显示物种文字。主画板上方是物种、草稿状态、新画纸和画具开关；下方固定三个创作操作：保存、看看它、送到大自然。直接去花园与声音收在左侧轻量入口，保持可发现性。画具增加即时笔触示意，保留工具、十二色、粗细、轻重、蝴蝶对称、撤销和重做。

网页“空间布局”只模拟透视；不用于验证真实距离和角度。平面细节保持同一组件和状态，供检查字号、间距。物理尺寸不随网页缩放改变。实现时保留系统 Bar 布局行为，不能用一张网页替代空间容器。

## 控件状态

| 状态 | 视觉与行为 |
| --- | --- |
| 默认 | 深色图标与文字；中性底色 |
| 选中 | 浅紫实底 + 勾选或底部标记；选择不会随凝视改变 |
| 凝视 / 键盘聚焦 | 单一目标外框增强 + 轻微亮底；不添加选中勾 |
| 按下 | 底色加深；不移动布局 |
| 禁用 | 保留可读标签，降低背景对比；不能触发 |
| 保存中 | 原按钮显示忙碌状态，阻止重复操作；画纸保持可见 |
| 保存完成 | 状态处显示“已保存到作品册”，不遮画纸 |
| 失败 | 明确说明未完成、保留画作，并给重试；原型评审工具可模拟 |

颜色用外环与勾标记选中，不能只靠颜色；蝴蝶以外的对称关闭且说明原因。橡皮不显示色彩沉积；填色不使用粗细和轻重。笔触预览随有效工具参数变化。

## 交互边界

原型包含：四纸切换、分物种草稿、区域遮罩涂色/填色/橡皮、蝴蝶镜像、撤销重做、笔触示意、保存及作品册继续编辑、删除确认、新画纸确认、画具隐藏恢复、声音入口、模型/花园衔接示意。只有在点击保存时写入本浏览器的独立原型存储；不会读写 Android 作品。示例配色、错误模拟、布局切换放在评审栏，不进入产品 UI。

“看看它”只展示原型的过渡状态与当前画作，明确标注待接真实空间模型；“送到大自然”演示先保存再等待场景就绪的流程，不能声称已经生成 3D 或进入真实 Stage。确认后复用现有原生 PreviewScene / StageNavigation，不重造场景逻辑。

## 动效与性能

凝视 100–120 ms，状态反馈 150 ms，面板出现 220 ms；不加入持续装饰动画或背景模糊。尊重减少动态效果设置。画纸资源启动预读，切换复用内存；布局不因状态提示变化跳动。正式版本手势点击区至少沿用现有 48–54 dp，完整检查 PICO 实际可读性，不能把网页像素当作真机 dp。

## 原生映射与验收

| 原型 | 现有原生实现 | 后续验证 |
| --- | --- | --- |
| 顶部选择项 | StudioScreen.kt / SpeciesBar → TabBar.item | 独立 Hover，直接切纸，无共享点击父节点 |
| 主画板 | CanvasScreen + PaintView | 冷启动可见、笔触连续、按钮可点击 |
| 右侧画具 | ToolScreen + Main.kt / Subwindow | 铺满 360 dp，25°，移动跟随，无灰边 |
| 凝视 | HoverSurface / SpatialHoverEffectGroup | 真机独立目标；不使用网页 hover 替代 |
| 作品册与预览 | AlbumScreen / PreviewScene | 草稿与选中作品独立，正确续画/预览 |

先核对浏览器各状态与布局，再以原生固定视角截图逐项比较；用户真机确认前不得写“还原通过”。视觉批准、代码检查、头显视觉和性能测量分别记录。
