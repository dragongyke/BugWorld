# V3：批准资产接入应用

日期：2026-10-09。Android/Kotlin、PICO Spatial SDK **6.1.0**，应用版本 **1.0.3 / 3**。只更新 `codex/bugworld-v1`。

后续状态：用户的真机反馈证明 1.0.3 的光照与天空显示未达到目标。1.0.4 修正及设备安装记录见 [Lighting-Water-Fix.md](Lighting-Water-Fix.md)；下文为 1.0.3 当时的实施记录。

## 已实现

| 范围 | 实际变化 |
| --- | --- |
| 资产替换 | 运行目录仅 `assets/v3`；五份 GLB 与用户批准文件逐字节一致。旧 JSON 模型、模板、程序摆动和生成脚本删除，无旧模型回退 |
| 空间 UI | 使用 SDK 原生 `TabBar`，含品牌、四类昆虫、作品册和画具入口；画具在右侧、作品册在左侧，分别使用 WindowContainer |
| 绘画 | 批准线稿降采样为 1024px，区域遮罩保持整数编号；保护固定线条/斑点，保留蜡笔积色、擦除、撤销及正确的蝴蝶对称轴 |
| 3D 预览 | 在画纸自身 SpatialView 的中心前方显示真实模型；异步加载并完成涂色后挂载，支持转向、缩放、展翅；关闭/失败/取消正确释放 |
| 玩家图案 | 按真实 GLB 的材质和 UV 分别投影；保留左右差异、蜡笔笔痕、留白，更新基础颜色时保留法线、粗糙度与骨骼 |
| 花园 | 使用批准的荷塘 GLB；暖色主光带真实阴影、冷色补光、环境反射与漫反射 IBL；背景仍来自批准天空 |
| 原生动画 | 每虫五个 GLB 片段，共二十个；起飞先开壳、降落反向收拢；毛毛虫轻触好奇、快速触碰缩身，蝴蝶可在手上理触角 |
| 活动与互动 | 路线从实际树干和荷叶表面采样；独立区域避免同物种占同一点；手部接近后停留，离手沿平滑路径回栖息位置 |
| 放生顺序 | 先保存 → 异步载入环境/作品/音效 → 场景可见且资源完成后三帧 → 提交队列 → 腾位 → 微光、局部暖光、定位音效与模型淡入 |
| 容量与作品册 | 最多十只，最早放入者先用 1.2 秒退场；重复放入同一作品不会复制。加载期间禁用再次放入，防止请求互相覆盖 |
| 历史数据 | 旧作品转换前备份 PNG 与元数据，保留编号、日期、队列；旧/损坏草稿覆盖前归档。迁移失败不覆盖别的作品，也不锁住整个画板 |
| 生命周期 | 原生动画和声音跟随可见性/生命周期暂停；Stage 退出成功才恢复窗口，退出失败仍能重试 |

音乐使用原创 96 BPM 合成曲及现有自然声，未识别或复用商场录音。IBL 从批准的 LDR 天空作格式转换、GGX 预滤波和 SH 积分，没有宣称恢复真实 HDR 拍摄光照。

## 验证与证据

- 完整命令：`:app:testDebugUnitTest :app:lintDebug :app:assembleDebug` 通过；**85 项测试，0 失败；Lint 0 错误、33 条警告**。包哈希和检查状态见 [构建验证](V3-Build-Verification.json)。
- [APK 资产校验](V3-Asset-Verification.json)：模型哈希、二十个动画、嵌入材质、模板像素、禁止旧目录、GLB/WAV/KTX 不压缩打包。
- `scripts/assets_v3_package.py` 对已批准模型/矢量锁定哈希，文件变化会拒绝重写批准清单；`assets_v3_runtime.py --apk …` 验证最终打包内容。
- `scripts/assets_v3_environment.py --check` 校验六面、五级 GGX、浮点像素、SH 数值、KTX 结构和源图哈希；SDK 6.1.0 的真实接口已编译核对。
- `scripts/verify_paint_v3.py` 验证实际材质/节点绑定、导出 UV 方向与受保护遮罩；见 [涂色核对](V3-Paint-Verification.json)。
- 路线核验：37,716 个地面姿态距真实表面最多 3.04 mm（含设计的 3 mm 接触偏移）；4,732 个巡航锚点距实体几何至少 14.12 cm，见 [检查报告](V3-Route-Verification.json)。`scripts/verify_routes.ps1` 导出真实 Kotlin 采样 CSV，再由 Blender 执行 `scripts/assets_v3_routes.py --output-dir .work/v3-routes --verify-samples .work/v3-routes/kotlin-poses.csv` 独立核验。
- 独立代码审查发现的编辑目标误写、草稿初始化锁死、退出失败无法重试、路线槽位冲突、地面姿态不一致、第五动作不可达和加载取消资源缺口均已处理。

## 仍需真机验收

本轮设备检查尚无 ADB 连接，**未安装或声称达到批准渲染图的真机画质**。以下不能用编译和文件校验代替：

1. 原生 GLB/骨骼/KTX 在目标头显的实际载入；透明苔藓、翅膜、甲壳、水面反射与光照强度。
2. TabBar 尺寸、左右窗口、画纸前方预览的真实视角；蜡笔输入手感与连续纹理更新延迟。
3. “送到大自然”首次及重复进出 Stage、满十只替换、音画定位与关闭后窗口恢复。
4. 手指/掌心识别、飞近和离手、触碰动画，以及完整虫体与环境/手部之间的接触效果。
5. 十只同场的 CPU/GPU 帧时间、原生内存、发热和连续运行稳定性。

Blender 体积雾、面积灯和后期微光没有自动移植成同等实时效果；目前使用 SDK 原生光照、阴影、IBL、局部光和粒子。表面锚点/轨迹验证也不等同于每一根足肢的实时 IK 或完整碰撞模拟。

更新安装使用 `adb install -r` 保留作品；APK 为 `app/build/outputs/apk/debug/app-debug.apk`。统计单独见 [Implementation-Metrics.md](Implementation-Metrics.md)。
