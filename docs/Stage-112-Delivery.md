# BugWorld 1.0.12 · 碧绿森林体验包

2026-10-22 已完成构建和包校验。用户选择稍后佩戴体验，本次只准备安装包，**尚未安装，也没有真机画质/帧率验收**。

## 本版内容

- 把已审阅的原生绿色森林场景接入应用，保留其材质图、日光阴影、环绕森林背景与双层法线动态浅水；使用同源实拍 HDR 生成环境光。
- 删除包内旧夜景场景、旧星空及水面反射资源；四种批准昆虫、画纸和 Shared Space UI 资产保持不变。原生场景中的静态展示昆虫不随包进入花园。
- 20 条新几何接触路线：10 条叶面、6 条倒木、4 条树桩；独角仙沿木面闭环爬行，瓢虫/毛毛虫沿叶面，蝴蝶保留停栖/飞行。路线是局部短循环，尚不是长距离漫游。
- 修正新入场的叶面/木面位置，均落在初始朝向的前方视锥。继续等待场景完成后才放生并播放入场反馈。
- 加载取消时保留并释放 bundle 所有权，避免中途退出丢失资源。

- 119 项单测通过；Lint 0 error / 34 warning；APK 构建和 v2 签名验证通过，签名与 1.0.11 一致，可覆盖升级。
