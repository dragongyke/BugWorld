# Shared Space 预览优化

## 1.0.13 转腕候选 · 2026-11-04

1.0.5 的捏合拖动根据二维位移调整角度。1.0.13 候选改用原生捏合事件的空间姿态，昆虫保持在画板前的固定位置，转动手腕可绕三轴观察，松手保留角度。轻触仍触发物种对应的招呼动作。左右手换抓、纯滚转和追踪间断已做数学回归，佩戴体验待确认。见 [BW-21](Troubleshooting-Retrospective.md#bw-21--stage-切换与手掌接触2026-11-04进行中)。

## 1.0.5 范围与方案

- 按 2026-10-19 的反馈改进加载和模型手势；Stage 性能、树干、水面由独立任务处理。
- 画纸窗口就绪后准备当前昆虫。收起预览只隐藏、暂停，不销毁；再次打开复用模型。只保留一种昆虫，切换时释放旧资源，Stage 接管或关闭画纸时释放全部。
- 相同画作版本重复预览不再生成、映射和上传纹理；编辑后更新颜色，保留批准的模型、纹理分辨率和动画。
- PICO 6.1.0 原生空间命中：捏合拖动旋转，直接触碰立即回应，轻点/短捏合触发同一物种的触碰动画。旋转不误触动画，释放后保持角度；第二只手不抢占操作。
- 移除模型上的旋转、缩放、展翅按钮；画纸原有“看看它”在预览时变为“收起预览”。

## 验证

- 单测覆盖旋转保持、拖动与轻点区分、直接触碰、冷却、取消、双手输入及同画作版本复用。
- 日志记录 GLB 加载、实例准备、颜色映射/上传、首帧提交耗时；首帧提交不等于头显实际呈现，不能代替合成器数据。
- 构建和测试可在本机完成。速度、真实手势命中、画纸透传、窗口移动/关闭/Stage 切换需头显复核；无设备时不宣称真机通过。

## 本机验证结果 · 1.0.5

- **97 项单测通过**；Lint **0 错误、28 警告**；Debug APK 构建成功。
- 新增 10 项回归测试：9 项手势/动画测试与 1 项画作版本复用测试。先复现失败再修正；两项动画测试专门覆盖触碰后隐藏再打开、慢帧导致的冷却时钟偏差。
- 代码审查发现的预加载取消重来问题已修正：打开预览等待当前加载，上传颜色与模型预加载分别管理。冷却由手势输入统一决定，接受新触碰后从该物种触碰动画的起点播放。
- 为避免并行 Stage 修改影响结论，在 `.work/shared-space-validation` 中使用 `f0d5823` 基线加本轮 Shared Space 文件独立构建。这个 APK 不包含 Stage 候选资产和诊断改动。
- APK 内 37 个资源文件与构建输入一致；四种昆虫 GLB 与批准原件 SHA-256 一致。完整结果：[Shared-Preview-Validation.json](Shared-Preview-Validation.json)。
- APK：`deliverables/BugWorld-1.0.5-shared-preview.apk`。时长、Token、CLI 记录见 [Implementation-Metrics.md](Implementation-Metrics.md)。

## 真机待验

头显未连接，未安装此版，暂不填入速度改善百分比或空间输入通过结论。

1. 应用刚打开立刻点“看看它”，以及涂色一段时间后点开；比较 `BugWorldPreview` 的 `load_ms`、`instance_ms`、`show_to_submit_ms`。
2. 同一画作收起/打开三次：日志应有 `reuse`，不重复 `prepared` / `colors`；换物种只保留当前模型。改颜色后应看到更新。
3. 分别触碰四种昆虫、捏合拖动、释放、双手同时输入；旋转不触发问候，收起后画纸仍可正常绘画。隐藏三秒后重新打开，首次触碰应回应。
4. 移动画纸窗口、暂停/恢复、进入/退出 Stage、关闭窗口；确认空间命中跟随模型，无错误和遗留动画。

`BugWorldModels` 的 `copy_map_ms` / `upload_ms` 用于继续区分 CPU 颜色映射与原生纹理上传。实际冷/热加载比较与内存变化需在同一头显采样。
