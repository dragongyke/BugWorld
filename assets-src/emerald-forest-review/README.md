## 设计取向与检查

前方右侧主叶观察瓢虫，前方低叶放毛毛虫，蝴蝶停在花瓣上，独角仙放在左侧倒木的上表面。后方主叶降低、叶面朝中心。保持已批准木头和叶片的尺寸，通过位置、方向和数量组织小型场景。

- 已检查：主叶在 1.15 / 1.65 m 眼高的正面可见性；39 组叶片与木头、岸面、苔石、其他叶片的实际三角形相交为零。
- 未覆盖：昆虫全动画、完整闭环路径、手指交互、所有眼位、低帧率时的碰撞；不能据此宣称所有穿模已修复。
- 水面仅两个三角形，当前是静态 PBR 材质样本；参数含艺术化 metallic 0.38，不是物理准确的水。流动法线、Fresnel/反射与设备性能须在后续材质验证完成。
