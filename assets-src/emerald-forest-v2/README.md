## 当前产物

- `garden.glb`：真实花园几何、材质与浅水底；151,989 三角形，38 个网格、18 种材质。
- `forest-background.glb`：3,968 三角形、12 m 背景壳体；真实 8K 摄影全景缩至 4096×2048，没有放大小图冒充清晰度。
- `emerald-forest-review.blend`：可编辑环境；四种已批准昆虫由构建脚本引用，未重复嵌入环境包。
- `front/right/back/left.png`：实际导出 GLB 重新导入后的四向 Cycles 渲染。光照、反射与色调映射不能当作 PICO 真机效果。
- [原生水材质工作台](../emerald-water-editor/README.md)：双层流动法线、森林环境反射和独立移动端打包；随后通过[原生材质对照](../emerald-native-materials/README.md)接到本花园的编辑器场景，尚未接入 Android 应用。

## 本轮改动与证据

| 问题 | 已做的修正 | 验证范围 |
| --- | --- | --- |
| 远处有水平青色断层 | 方形水面和水底裁为不规则池形，藏入岸下 | 四向真实 GLB 渲染 |
| 背景清晰度不足 | 4K 森林背景及同源 HDR 环境光，增加 8 根实体中景树干 | 实际像素尺寸、四向视角；尚无头显验证 |
| 岸边像整齐草环 | 降低岸面隆起、12 组扫描石、40 组低蕨；树根按地形埋入 | 30 组主要叶片与叶/木/岸/石的三角相交检查为零 |
| 前方水域被叶片挤占 | 删除被倒木遮住的左侧重复观察叶，移动两片前叶；保留物体尺度 | 5 片主叶的站姿/坐姿朝向及四向实际渲染 |
| 水面法线无效 | 先以不透明材质烘焙，再设置透明度；断言法线像素有变化 | 原失败贴图全部为 RGB 128；修正后有有效切线法线 |
| 复杂度上涨 | 远景烘在背景中；低蕨使用 512 贴图；近景纹理保留 | 几何、所有嵌入纹理及旧运行资产哈希由脚本检查 |

接触检查不覆盖昆虫完整动画和循环轨迹。151,989 面不证明流畅；未运行新场景的 GPU/长帧对照。

## 对照仍未通过的部分

- 参考图的阳光、苔藓层次与柔和空气感仍未完全形成；不能把高清摄影背景等同于完成美术还原。
- 岸边与远景的颜色和轮廓还需统一。已将外围升高量从约 0.95 m 降至 0.38 m，缓解裸露草坡，但仍不能等同于参考图的自然接壤。
- GLB 水面采用薄层透明混合，不是折射模拟；原生水样已接到完整环境进行对照，仍是不透明水。两者尚未统一，不能拿离线水面代替应用验收。
- 原生编辑器暴露了白石头、颜色偏差和光照不足；显式材质已改善前两项。单独日光 GLB 导入未得到可确认的灯光组件，未声称已完成日光阴影还原。
- 循环路线、原生照明接入、10 只昆虫及连续转头的真机验证未做。1.0.11 的运行资产和 APK 保持原样。

## 失败尝试保留

1. 简单程序树轮廓与草环不能支撑参考图质感。
2. Jacaranda 下载文件实际含约 386 万三角形，按 14 实例烘焙超出显存/内存，出现黑图；进程退出成功也不能视为渲染成功。
3. 将离线树降到约 8% 后可渲染，但像空旷公园、树干剪影过重；`attempt-baked-forest.png` 是失败证据，不是当前候选。
4. Mossy Forest 摄影背景虽清楚，但灰绿杂枝的氛围不匹配，改为 Forest Slope。
5. 抬高岸边掩盖接缝又造成裸露草坡，后续降低坡高、加入稀疏中景树干和低蕨。不能把几何相交检查通过写成美术通过。

## 来源与复现

新增外部素材均为 Poly Haven CC0：[Forest Slope](https://polyhaven.com/a/forest_slope)（Andreas Mischok）、[Fern 02](https://polyhaven.com/a/fern_02)、[Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01)。下载 URL、字节数和哈希见 `sources/*SOURCE.json` 及对应模型目录。近景木头与昆虫沿用项目已批准来源。

1. `python scripts/fetch_emerald_sources.py`
2. 使用 Blender automation runner 执行 `scripts/build_emerald_forest_v2.py`，输出目录设为本目录。
3. `python scripts/verify_emerald_forest_review.py --directory emerald-forest-v2`

完整证据为 `build-report.json`、`contact-check.json`、`verification.json`；历次诊断见 `docs/Troubleshooting-Retrospective.md`。

## 2026-10-21 当前版本（替代上面的阶段性状态）

- 当前 `garden.glb` 为 **150,789 三角形、37 网格、17 材质**；背景仍为 3,968 面。删除 8 根抬头可见截口的辅助树干，真实木头、低蕨和石头负责近中景衔接。
- 原生日光 2400 lux 配合同源森林 HDR 8 EV；天空球通过持久化阴影组件关闭投影，避免遮住整个花园。独立项目重新打开后，背景与叶片/花瓣/木面阴影同时可见。
- 岸边外缘向下收口，石头改为不规则组合；原生浅水为 0.65 透明度加染色池底，保留双层流动法线。可平铺池底替换错误模型 UV 图集，消除黑带；没有物理折射。
- 叶片、岸边、池底、石头、花瓣和蕨类采用显式材质；蕨类仍用 MASK alpha。颜色 Power 2.2 是近似线性化，不是精确色彩校准。
- `editor-native-*-final.png` 是独立项目重开后的原生前/右/后/左、坐姿、抬头六视角。四只虫为批准模型的固定姿态；网格、轴线为编辑器辅助显示。
- [便携原生场景](../emerald-native-scene/README.md) 已保存全部引用、原生灯光与七种材质，mobile 编译通过。自动检查 30 组主要表面无交叉，29 个现有应用资产与 APK 哈希保持原样。
- 全部嵌入 GLB 纹理 RGBA8+mip 保守估算约 **206.7 MiB**，较第一轮增量约 **62.7 MiB**，不是实际 GPU 驻留。
- 仍需应用内 IBL/材质接入、物种路线和真机画质/性能验证。全景存在固定视差和顶点投影模糊的限制；不宣称概念图 100% 像素还原。
- 失败保留：延长 8 根辅助树干到背景外仍露出截口，最终移除；`editor-native-canopy.png`、`editor-canopy-extended.png` 为两次失败，`editor-native-canopy-final.png` 为移除后的实际视图。
