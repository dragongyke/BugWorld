# 昆虫无损合批派生资产

来源是 `assets-src/v3-review` 中用户已批准的四个 GLB，原始资产与 Blender 母版不变。

| 昆虫 | 原图元 | 合并后图元 | 三角面（不变） |
| --- | ---: | ---: | ---: |
| 蝴蝶 | 68 | 8 | 55,688 |
| 独角仙 | 150 | 11 | 96,244 |
| 瓢虫 | 139 | 11 | 71,428 |
| 毛毛虫 | 92 | 4 | 117,128 |

只合并同一父节点、相同骨骼蒙皮、相同材质、局部变换为单位矩阵且没有独立动画的网格。绘画映射依赖的命名网格单独保留。合并不减面、不重烘焙；顶点属性（位置、法线、UV、权重、关节编号）、三角索引、骨骼、动画采样、材质和嵌入图片均做数据一致性检查。节点/访问器重新编号后再读取实际输出验证，清单见 `manifest.json`。

生成：`python scripts/merge_insect_draws.py`。Blender 独立进程重新导入源文件和派生文件，以相同相机/灯光渲染静止及飞行或爬行姿态；结果见 `render-verification.json`。本地检查 `.blend` 和中间渲染位于 `.work/insects-batched-renders`。

这些数字表示 glTF 图元数量，不是实测渲染调用或 FPS；移动端性能、输入与高亮须独立验证。当前不改变 Opacity 组件、动画播放策略或材质克隆策略，以便隔离此次合批的影响。
