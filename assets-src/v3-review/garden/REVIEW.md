# 暮色荷塘 · 实际场景资产样景

状态：资产候选，待用户审核；未接入 Android 应用。这里检查主观察方向的场景资产，不作为完整 Stage 或头显截图。

## 实际交付

- `garden-naturalized.blend`：可编辑主场景，包含几何、PBR 纹理及审核光照。
- `garden.glb`：环境几何和图像材质；昆虫为各自独立 GLB。
- `garden-roundtrip.png`：重新导入上述 GLB 后，使用审核灯光实际渲染。
- `garden-populated.png`：相同场景加上本轮蝴蝶、瓢虫 GLB 的组合预览；不包含应用生成或交互逻辑。
- `garden-report.json`、`roundtrip-report.json`、`composition-preview.json`：几何数据、源文件哈希、导入检查和组合位置。
- `ASSET-SOURCES.md`：扫描枯木、树根、苔藓的 CC0 来源与下载校验。

## 与确认图的对应

保留蓝紫暮色、巨型荷叶、前景斜倒木、右侧主断桩、粉色荷花、水面及暖色萤火。荷叶、叶脉、茎、露珠、芦苇、花瓣、水面均为可编辑几何；树皮、树根和苔藓采用扫描资产。

制作时替换了生硬的程序树皮和苔藓，调整扫描枯木的方向、粗细、根部收分与破口，调整荷叶褶皱与边缘曲面，打散芦苇的弯曲方向，并分别设置前景边光和背景蓝光。补接源苔藓缺失的透明遮罩，避免颜色 JPG 的黑底被渲染为实心碎片。过白、外形不符的 `dead_quiver_trunk` 已淘汰。

这是对确认图的三维重建和组合。植物分布、具体树皮纹理、木桩破口、花瓣形状等并非逐像素复制；没有把设计图贴到背景代替真实场景。

最新组合图（2026-10-09 12:24:40）内部复核结论：可提交真实资产候选审核；未见明显透明黑片、严重穿插、断裂或大片缺材质。仍存在荷叶/花瓣偏规整、芦苇排列重复、远景层次不足，以及暖色边光、蓝雾纵深和湿润光感弱于批准图的问题。没有将这些差异标记为已解决。

## 数据与导出检查

环境为 150 个网格对象、740,784 个三角形。GLB 约 60 MiB；准确文件长度与 SHA-256 以总包 `asset-manifest.json` 为准。回导检查 UV、材质和实际引用的打包图像；总包另检查苔藓透明通道实际覆盖 0–255。

图像材质包括 Base Color、Normal、Roughness/ARM 和透明遮罩。PBR 颜色不包含渲染时的阴影。组合图的昆虫来源和变换有独立记录；它们没有写入环境 GLB，也没有调用旧版昆虫。
