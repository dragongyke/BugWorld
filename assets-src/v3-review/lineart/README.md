本目录是实际可编辑 SVG 与由 SVG 栅格化的 PNG，不是效果图。依据已确认的 `01-insect-sheets-v1.png` 逐种手工设置 Bézier 控制点，参考 `04-shared-space-multiwindow-v2.png` 的紫色导航图标语言。没有改动应用代码，也没有把批准图的像素提取成产品线稿。

## 先看这三张

- `comparison-approved-vs-svg.png`：左侧是批准图的原始裁剪，右侧是实际 SVG 的栅格结果；两侧按同一原始裁剪框比例展示，未用不同的内容包围盒伪装匹配。

- `masks-contact-sheet.png`：最终区域遮罩的伪彩色检查图，固定黑斑与躯干区域排除在可涂区域之外。

## 轮廓与区域约定

| 独角仙 | 朝右侧面、长弓形背甲、两支反曲角、三条可见腿 | 3，背甲、前胸及短角、头部及长角 |
| 瓢虫 | 椭圆整壳、窄双线中缝且底端闭合、两个长椭圆斑、六条接壳腿 | 4，左右背甲、头盖、前胸 |
| 毛毛虫 | 朝右软体连续轮廓、独立体节曲线、八只可见足垫、单眼和触角 | 10，批准稿中实际可辨的尾端 + 8 节 + 头 |

区域路径是闭合曲线，不依赖可见细线自行围成填色边界。固定图案由单独的遮罩排除，薄装饰脉线不把同一翼面拆成多块。整张画纸按物种原始长宽比放进方形画布；毛毛虫保留细长比例。不要把整个 2048 方图直接作为导航图标。

## 编辑与再生成

源文件：`scripts/assets_v3_lineart.py`。主形状是显式的 `M/C/L/Z` 路径常量，未采用旧版程序模型的椭圆轮廓。源坐标对应批准图中每一物种的裁剪框；`manifest.json` 内 `source_coordinate_box` 与 `source_to_sheet` 给出到 1024 画布的变换。蝴蝶以源坐标 x=251 镜像，右侧变换为 `translate(502 0) scale(-1 1)`。

SVG 可以直接在矢量工具中编辑；要保留到下一次生成，请将修改后的 `d` 同步回脚本。再次运行会覆盖本目录生成文件。模型/UV 制作者可直接读取 manifest 中每个区域的 `d` 与镜像变换，无需再猜一套轮廓。

脚本使用 Python 的 Pillow、NumPy 和本机捆绑的 Node sharp/librsvg；Pillow 只合成检查图与编码遮罩，线稿本身由 SVG 路径产生。运行命令：

```powershell
& 'C:/Users/Admin/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' scripts/assets_v3_lineart.py
```

仅需要搬动运行环境时可设置 `BUGWORLD_NODE`、`BUGWORLD_SHARP`。脚本所有输出、临时栅格输入均限于本目录，临时目录在完成后清理。

## 自查与限制

已逐张查看真实 SVG 栅格、原稿并排图、遮罩图及实际尺寸图标；第二轮修正了偏细蝴蝶躯干、瓢虫脱离腿根/底部中缝和独角仙腹缘/腿根。生成时检查 SVG 可解析、命名节点不重复、所有区域路径闭合、2048 尺寸、透明通道范围、区域编号完整、每个区域足够大且为一个连续区域。阈值栅格化产生的零星 1–7 像素边缘孤点会清除；清除数量记录在 manifest，不是隐藏改动。

SVG 保留线条粗细层级和深色固定标记，较批准图的纸纹/扫描感更干净；这是可缩放线稿资产的差异。图标为小尺寸阅读减少了细脉与斑点数量，保持各物种的关键轮廓。此处完成的是资产自查，不等于用户最终批准、模型渲染验收或应用内效果验收；尚未接入应用。
